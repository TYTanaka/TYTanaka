## 代表作

### 席次まるっと

結婚式のゲスト名簿・招待・出欠管理・席次表づくりをひとつにしたWebアプリです。

- Live: https://tytanaka.github.io/sekiji-marutto/
- Repo: https://github.com/TYTanaka/sekiji-marutto

### さくら席

劇団の実公演（451席）で実際に使われている、スマートフォン座席予約システムです。ゾーン予約・QR受付・当日の自動座席割り当てに対応しています。

- Live: https://sakura-seats.pages.dev/
- Repo: https://github.com/TYTanaka/sakura-seats

### みつもりまるっと

式場の見積もりを9つの共通カテゴリに揃えて比較し、最終的な総額の範囲まで予測する結婚式見積もりWebアプリです。

- Live: https://tytanaka.github.io/mitsumori-marutto/
- Repo: https://github.com/TYTanaka/mitsumori-marutto
